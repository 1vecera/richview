# Where `hn-comment-mentions-monthly.csv` comes from

A copy of `examples/openai-vs-anthropic/data/charts/hn-comment-mentions-monthly.csv`, the flagship report's own file (Hacker News comments that mention OpenAI or Anthropic, by month, January 2023 to October 2026; the flagship's ledger records its source and method). `anthropic_share` is `anthropic_comments / (openai_comments + anthropic_comments)`. The folder holds a copy because a report reads only files inside its own folder.
