Install the command

Install the latest GitHub release on macOS Apple Silicon or Linux x64 with glibc 2.35 or newer. On Linux, SQL queries and Parquet files also need kernel 6.2 or newer with Landlock ABI 3. Windows and Intel Mac are not supported yet. Windows x64 has its own command, below. Intel Mac is not supported yet.

The installer verifies the archive and installs into a new ~/.richview directory. It does not change your shell configuration or start a service: the PATH line applies to this shell, so add it to your shell profile to keep it. If that directory already exists, the installer will not overwrite it: update as below.

Publishing goes to RichView Cowork, the report server: RichView hosts it at app.richview.ai, or you run your own with richview server. See publishing.

Windows x64

It has everything the macOS and Linux command has: the local preview, the MCP server, PDF output and SQL data sources. PDF output prints through Microsoft Edge, which comes with Windows. Each release is walked end to end on a fresh Windows Server 2025 machine before it ships; Windows 10 and 11 on x64 should behave the same but are untested. The programs are not signed yet. Uninstall

The uninstaller keeps your reports and RichView state, and refuses to remove changed, missing or extra installation files. Remove any PATH entry you added yourself.
