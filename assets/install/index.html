Install RichView

Make a report locally with the RichView command-line tool.

Ask an agent

Give your coding agent this instruction:

Install the command

Install the latest GitHub release on macOS Apple Silicon or Linux x64 with glibc 2.35 or newer. Linux SQL data sources also need kernel 6.2 or newer with Landlock ABI 3. Windows and Intel Mac are not supported yet. Windows x64 has a preview, below, without PDF output or SQL data sources. Intel Mac is not supported yet.

curl -fsSL https://github.com/1vecera/richview/releases/latest/download/install.sh | sh

The installer verifies the archive and installs into a new ~/.richview directory. It does not change your PATH or start a service. If that directory already exists, the installer will not overwrite it: update as below.

Windows x64 (preview)

A preview for Windows 10 and 11 on x64, not a supported platform yet. It has the command line with its local preview and MCP server. PDF output and SQL data sources are not available on Windows yet, and the programs are not signed. In PowerShell:

irm https://github.com/1vecera/richview/releases/latest/download/install.ps1 | iex

The installer verifies the archive and installs into a new .richview folder in your home folder. It does not change your PATH or the registry and starts no service. To uninstall, which keeps your reports:

powershell -ExecutionPolicy Bypass -File "$HOME\.richview\uninstall.ps1" -Uninstall

Update

To move an existing ~/.richview to the latest release, uninstall it and install again. Your reports and RichView state are kept.

sh "$HOME/.richview/uninstall.sh" --uninstall --prefix "$HOME/.richview"
curl -fsSL https://github.com/1vecera/richview/releases/latest/download/install.sh | sh

Uninstall

sh "$HOME/.richview/uninstall.sh" --uninstall --prefix "$HOME/.richview"

The uninstaller keeps your reports and RichView state, and refuses to remove changed, missing or extra installation files. Remove any PATH entry you added yourself.

Make your first report

Use the installed executable directly. Pick a new folder name if richview-demo already exists.

~/.richview/bin/richview learn
~/.richview/bin/richview init richview-demo
~/.richview/bin/richview validate richview-demo/report.rmd
~/.richview/bin/richview check richview-demo/report.rmd
~/.richview/bin/richview generate richview-demo/report.rmd

Inspect the diagnostics, fix any issues and check again. Open richview-demo/Rendered/report.html in your browser. The starter data is fictional; replace it with your own data when ready.

For MCP and other tools, see the tool guide.
