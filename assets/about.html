About RichView

Hi, I’m Daniel Večeřa. I’m the founder of RichView, and I build it in Prague.

What it is

RichView is a local CLI that lets you generate beautiful HTML reports from simple Git-storable text files. The charts come from RichView’s own charting library.

Want to see one? The docs open with working reports, each with its source and data.

Open source

RichView is open source under the MIT license. The code is on GitHub: github.com/1vecera/richview.
