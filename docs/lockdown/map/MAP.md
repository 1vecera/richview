Each of the 796 cards is a node, and a card links to another when its text names that card's item ID (such as `ARC-06`) or entity ID (such as `D-ARTIFACT`, resolved to the card that defines it). A link's type says where the reference sits: **decides** runs from a cross-part card (OPN-50 to OPN-68) to each card whose conflicts say "answer OPN-xx first"; **conflict** means the reference is in `conflicts`, or a cross-part card names a card it decides; **depends** means the reference is in `proposed`, `question` or `recommendation`, so the card's answer builds on the other; **mentions** means it is only in `why` or the options. When one card references another in several fields, the link keeps its strongest type (decides, conflict, depends, mentions). "Depends on" lists the cards a card's own answer builds on; "depended on by" lists the cards whose answers build on it, which are the ones to recheck when it changes.
