          Write the interactive report (default) or a PDF printed by a local Chromium-family browser

          - report: The interactive HTML report
          - pdf:    A PDF printed by a local Chromium-family browser

      --page <PAGE>
          Paper size of a PDF

          [possible values: a4, letter]

      --browser <BROWSER>
          Chromium, Google Chrome or Microsoft Edge executable for PDF output (or RICHVIEW_BROWSER)

      --settle-timeout <SETTLE_TIMEOUT>
          Seconds a PDF waits for fonts and charts to settle
          
          [default: 30]

Upload, verify and abort integrity-pinned remote data and media

Usage: richview asset <COMMAND>

  verify  Check stored objects against reference files (YAML or JSON)
  abort   Abort journaled multipart uploads (all, or those whose SHA-256 starts with a prefix)
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
