# Format probes

These are the probe reports behind the facts marked (re-run) in [Format and types](../../../guide/format-and-types.md). Each folder is one report folder: a `report.rmd` and its inputs, without outputs. All were run on 22 October 2026 with the release build of `b4db233` (`target/release/richview` 3.0.0-alpha.0, chart runtime from `dist/web`). To repeat a run, copy a folder to a scratch location, so `Rendered/` is not written into the repository, and run `richview validate report.rmd --format json`, `richview check report.rmd --format json` and `richview generate report.rmd --format json` there, giving `check` and `generate` `--public-dir` pointing at `dist/web`. Messages that name the report folder are quoted with `<report folder>` in place of its absolute path.
