Upload a data or media file and print its integrity-pinned reference

Usage: richview asset put [OPTIONS] --to <STORE> <FILE>

Arguments:
  <FILE>  

Options:
      --to <STORE>         Store profile name
      --public             Write under the public prefix with immutable caching (private by default)
      --type <MEDIA_TYPE>  Media type when the extension is ambiguous, for example audio/webm
      --stores <FILE>      Store profiles file [default: $RICHVIEW_STORES, then $XDG_CONFIG_HOME/richview/stores.yaml]
      --format <FORMAT>    [default: pretty] [possible values: pretty, json]
  -h, --help               Print help
