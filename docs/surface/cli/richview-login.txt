Sign this computer in to a RichView server, so publishing needs no token again

Usage: richview login [OPTIONS]

Options:
      --server <SERVER>              Server URL (https, or http on loopback); defaults to your publish server [env: RICHVIEW_SERVER=]
      --with-token                   Read a CLI token from standard input instead of signing in through the browser
      --device                       Sign in with a short code you confirm on any device, not in this computer's browser
      --expect-account <ADDRESS>     The account's address that the sign-in must be for; needed when nobody is at the terminal to confirm whose it is
      --expect-organization <NAME>   The organization the sign-in must be for, by its name as the server writes it
      --expect-organization-id <ID>  The organization the sign-in must be for, by its id, which a rename does not change
      --no-browser                   Open no browser: print a short code and a page address to confirm on any device (or set RICHVIEW_NO_BROWSER)
      --format <FORMAT>              `pretty` for people, `json` for agents [default: pretty] [possible values: pretty, json]
  -h, --help                         Print help
