Create a report or publish another version at its address

Usage: richview publish [OPTIONS] <INPUT>

Arguments:
  <INPUT>  The report's `.rmd`, saved in its own folder (a folder holding one `.rmd` also works)

Options:
      --style <STYLES>           Style (a builtin name or a file in the report folder) replacing the source's `styles` for this call; repeatable
      --connectors <CONNECTORS>  Trusted `connectors.toml` binding the names in `report.connectors.yaml` to data sources [env: RICHVIEW_CONNECTORS=]
      --server <SERVER>          Server URL (https, or http on loopback) [env: RICHVIEW_SERVER=]
      --choose-server            Choose and remember a publish server again (without RICHVIEW_SERVER)
      --token <TOKEN>            Bearer token of the server; defaults to the sign-in `richview login` keeps [env: RICHVIEW_TOKEN]
      --slug <SLUG>              Address of the report; defaults to the frontmatter slug, then the title
      --new                      Allow this file to create another address on the same server
      --visibility <VISIBILITY>  Who can open the report: private (you and the people you name), org (every member of your organization) or public (anyone with the link). With public sharing, anyone with the link can read the original Markdown and save a copy. Left as it is when omitted [possible values: private, org, public]
      --format <FORMAT>          `pretty` for people, `json` for agents [default: pretty] [possible values: pretty, json]
  -h, --help                     Print help
