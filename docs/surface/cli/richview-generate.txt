Write the self-contained report, or a PDF, into the report folder's Rendered/

A deck, a `.rslide` file, is written as slides: one screen for each slide, and a PDF of one 16:9 page a slide.

Usage: richview generate [OPTIONS] <INPUT>

Arguments:
  <INPUT>
          The report's `.rmd` or a deck's `.rslide`, or the folder holding it; a folder of report folders stands for every report below it

Options:
      --style <STYLES>
          Style (a builtin name or a file in the report folder) replacing the source's `styles` for this call; repeatable

      --connectors <CONNECTORS>
          Trusted `connectors.toml` binding the names in `report.connectors.yaml` to data sources
          
          [env: RICHVIEW_CONNECTORS=]

  -o, --output <OUTPUT>
          File name inside Rendered/; a name ending in .pdf implies --to pdf

      --to <TO>
          Write the interactive report (default) or a PDF printed by a local Chromium-family browser

          Possible values:
          - report: The interactive HTML report
          - pdf:    A PDF printed by a local Chromium-family browser

      --page <PAGE>
          Paper size of a PDF; slides print on 16:9 pages of their own
          
          [default: a4]
          [possible values: a4, letter]

      --browser <BROWSER>
          Chromium, Google Chrome or Microsoft Edge executable for PDF output (or RICHVIEW_BROWSER)

      --settle-timeout <SETTLE_TIMEOUT>
          Seconds a PDF waits for fonts and charts to settle
          
          [default: 30]

      --format <FORMAT>
          `pretty` for people, `json` for agents
          
          [default: pretty]
          [possible values: pretty, json]

  -h, --help
          Print help (see a summary with '-h')
