Delete a version for good; its address answers 410 and it can never be published again

Usage: richview report delete [OPTIONS] <SLUG> <VERSION>

Arguments:
  <SLUG>     
  <VERSION>  

Options:
      --yes              Delete without asking
      --server <SERVER>  Server URL (https, or http on loopback); defaults to your publish server [env: RICHVIEW_SERVER=]
      --token <TOKEN>    Bearer token of the server; defaults to the sign-in `richview login` keeps [env: RICHVIEW_TOKEN]
      --format <FORMAT>  `pretty` for people, `json` for agents [default: pretty] [possible values: pretty, json]
  -h, --help             Print help
