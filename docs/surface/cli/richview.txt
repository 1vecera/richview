Rich Markdown: render, check and publish reports from your agent

Usage: richview <COMMAND>

Commands:
  generate  Write the self-contained report, or a PDF, into the report folder's Rendered/
  validate  Check the structure of a report without rendering it
  check     Render the report and return every diagnostic and each chart's geometry
  init      Start a report folder from the template, never overwriting
  learn     Print the authoring guide, or one section of it
  mcp       Serve the RichView tools to an agent over MCP (stdio)
  publish   Publish a version of the report to a RichView server
  serve     Preview the report in a browser and reload it when the folder changes
  report    Delete, pin, unpin or regenerate a stored report on a server
  server    Run RichView Cowork, the report server
  asset     Upload, verify and abort integrity-pinned remote data and media
  image     Search Unsplash and place a credited photo in a report
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

init, validate, check, generate, publish and report exit 0 when no finding is an error, 1 on any error (a draft with block errors is still written) and 2 on a usage error. With --format json each prints one object: ok, status (clean or issues), output (the file written, or null) and diagnostics. learn prints text, and serve, server and mcp run until stopped. asset and image print their own JSON and exit 2 on invalid input or configuration, 3 when a transfer or Unsplash fails and, for asset, 4 on a verification mismatch.
