Re-render a stored version with this engine and say whether the HTML changes; stores nothing

Usage: richview report regenerate [OPTIONS] <SLUG> <VERSION>

Arguments:
  <SLUG>     
  <VERSION>  

Options:
      --server <SERVER>  Server URL (https, or http on loopback) [env: RICHVIEW_SERVER=]
      --token <TOKEN>    Bearer token of the server [env: RICHVIEW_TOKEN]
      --format <FORMAT>  `pretty` for people, `json` for agents [default: pretty] [possible values: pretty, json]
  -h, --help             Print help
