RichView shares Rust engines across native, browser, Node and editor hosts. The flagship's content, source ledger and research snapshot remain fixed when the renderer changes. This index points to executable contracts instead of generated capture archives; previous captures remain in [the merged baseline](https://github.com/richview-universe/richview-v3/tree/3c07128b7139687b754f6e1b5848c2a46c31cfe5/docs/evidence).

Chart/table resources are block-local inline or bounded CSV/JSON inside a dedicated report folder. Hosts provide explicit inventories and resolved bytes; header data registries and remote/SQL loaders are errors. Native math/layout performs no filesystem or network I/O. Schema adapters expose `.parse` and `.safeParse`, not general third-party Zod combinators. Explicit editor publication stores tokens in VS Code SecretStorage; it does not read plaintext `richview.apiToken` settings.

Native glyph heights are estimates even when SVG widths are constrained. Browser measurement and visual review remain necessary for font/layout changes. Standalone SVG references font families; offline HTML and PDF use packaged fonts. Hosted CI, deployed-site checks, full timing captures and GUI/editor installation checks have distinct scopes and must be recorded separately.

Behavioral browser suites select Chromium, Firefox or WebKit through `RICHVIEW_VERIFY_BROWSER`; each harness directory records `browser-environment.json`. Cross-engine coverage includes source fidelity, chart updates and recovery, keyboard/pointer interactions, source tables and downloads, standalone SVG, homepage authoring and showcase flows. The full report screenshot matrix, fixed timing budgets, PDF and trusted multi-touch injection use Chromium; focused ink measurements run in all three engines. SVG diagnostics compare transformed text geometry without including decorative paint halos; unsupported SVG geometry retains the client-rectangle fallback.

Native source undo has a WebKit limitation: navigating the preview iframe clears the parent textarea's history. An independent browser control records that capability before the undo/redo checks; source-byte preservation, paging, clipboard and mixed-line-ending checks run in all three engines.
