# RichView overview

RichView is a source-centered report product built in Rust. Analysts and coding agents edit Markdown, chart YAML, data and ordered styles, preview the rendered report, inspect actionable diagnostics and improve the source. Native CLI, server, MCP, editor and browser hosts use one report/chart engine.

Reports remain readable source files with embedded or caller-resolved data. Publication stores immutable versions and retained source/resources for regeneration. The browser provides source/style editing and substantial examples, including a sourced showcase with comparison, citations and chart expansion. A deterministic Rust motion reel shares the research data and native audio cue clock; the editor supplies source authoring commands.

See [the source contract](RMD-SPEC.md), [architecture](RUST-ARCHITECTURE.md), [features and verification](FEATURES.md) and [performance record](PERFORMANCE.md). The root README contains reproducible local build and preview commands.
