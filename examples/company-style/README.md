# Your Company Name Inc.

This fictional report uses one brand colour in `company.rstyle.yaml`. Change `colors.brand`, then run `richview check report.rmd` and `richview generate report.rmd` to see the derived style and series palette. Presets, colours and five-step settings are proposed under STY-73.

Logo files are embedded with their metadata, including EXIF, XMP and text; remove anything you do not want to share. Validation checks the image container and dimensions, so a file with corrupt pixels may still appear broken. On share cards, the company style's resolved accent takes precedence over the publication's accent.
