Repository snapshot dates establish provenance, not the date a screenshot was taken. The screenshots illustrate the tools and do not establish the report's capability rankings.

The original charts embed only the three bundled scientific text faces they use. Their SVG metadata contains the full MIT and SIL OFL notices; [Source Serif 4](licenses/source-serif-4-OFL.txt) and [Source Code Pro](licenses/source-code-pro-OFL.txt) notices are also retained alongside the files. [The renderer input and output manifest](editorial-charts.json) records exact source rows, source/runtime hashes, renderer commit and browser version. Rebuild with `node examples/openai-vs-anthropic/research/build_images.mjs` after the Rust release build, then explicitly update the image ledger hashes as a new reviewed image revision.

The replaced stock photographs and their credits remain in [the original media directory](../media/CREDITS.md) for snapshot history.
