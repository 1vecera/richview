# Chart craft review — 5 October 2026

Prepared for review. This follow-up implements Daniel's chart feedback in the existing Rust renderer and browser runtime. It does not claim complete parity, select new fonts or deploy a release. The earlier Highcharts visual-review PR is already merged; this is a separate review branch based on `8a0ec09f3814923fd4173116f1fa6f8cb7836800`.

The live comparison uses Highcharts 13.1.1, Apache ECharts 6.1.0, Plotly 4.1.1 and ggplot2 4.0.3 with R 4.6.1. It covers 50 reports across line, area, bar, scatter/bubble, pie and heatmap, with the same resolved rows and complete widget dimensions. Reports own their folders and inline YAML data/loading definitions. The local reference installation and 125 distinct official gallery pictures remain under `/home/vecera/tmp/chart-design-evidence/reference`; its corpus index records URLs, image paths, dimensions, chart states, hashes and capture provenance.

[Editable Figma study](https://www.figma.com/design/Y6wDEoZR1k3sFxhDDH26ki?node-id=25-2) contains 200 product chart components and gallery instances: 50 each in Sleek Light, Sleek Dark, Scientific and Brutalist. Live text, plot vectors, legends, 22 calendar overviews per theme, shared icon variants and semantic theme variables are editable. The competitor page has 24 matching studies across all six types and four engines. Browser-engine glyphs are outlines from actual settled browser print output; ggplot2 uses its materialized native glyph paths; embedded heatmap/gradient pixels become editable colored rectangles. Original PDFs and ggplot2 SVGs remain inspectable locally. Imported glyph coordinates are rounded to three decimals to bound connector payloads. The file lives in Daniel's myTeam drafts; no public sharing or library publication was requested.

The baseline and first two rounds compare matched resting data and dimensions, but their active reference windows were not aligned. Do not use those active pictures as zoom-parity evidence. Rounds 3 onward explicitly align temporal X windows; each engine still chooses its own internal margins and Y ticks. Resting glyph diagnostics and interaction recordings establish different things. Early partial captures remain archived but are excluded from the review index.

Highcharts uses adaptive datetime ticks and connected zoom, reset and navigator controls. ECharts separates emphasis, blur and selection for pie sectors. Its installed pie source informed the behavior study; RichView uses its own Rust hit testing and DOM bindings. Plotly integrates discoverable top-right tools, scroll zoom and range sliders. ggplot2 is a static reference for geometry and typography, not evidence of browser interaction parity. [Highcharts zooming](https://www.highcharts.com/docs/chart-concepts/zooming), [Highcharts tooltips](https://www.highcharts.com/docs/chart-concepts/tooltip), [ECharts doughnut emphasis](https://echarts.apache.org/handbook/en/how-to/chart-types/pie/doughnut/), [ECharts pie source](https://github.com/apache/echarts/blob/6.1.0/src/chart/pie/PieView.ts), [Plotly configuration](https://plotly.com/javascript/configuration-options/), [ggplot2 labels](https://ggplot2.tidyverse.org/reference/labs.html).

Presentation targets about three significant digits, with extra precision when needed to distinguish tight tick steps. Magnitude suffixes attach directly (`25k`); oil KBD values scale to MBD at 1,000. Arbitrary unit strings remain literal. Exact values and observations remain in tooltips, tables, source and original-row CSV downloads. Calendar labels support en-US by default, en-GB, cs-CZ, de-DE and ja-JP; timestamp geometry remains UTC.

Verification passed: Cargo formatting, native/Wasm Clippy with warnings denied, workspace tests, release build, fixture generation, all required native/editor/compat/types/browser/landing/showcase/reel/browser-API checks, source equality for all 50 reports, and native offline exports for all 50 Scientific examples. Additional four-theme browser checks and recordings cover time zoom/reset, numeric keyboard/wheel/brush zoom, series visibility, pie keyboard emphasis, gapless cells, original-row downloads and numeric-to-temporal updates without duplicate controls. Logs, manifests, `source-values.json`, `native-reports.json` and `verification/checks.json` are local evidence, distinct from hosted CI.

Remaining gaps: font selection is still open; native font bounds remain estimates while settled browser glyph bounds are measured. Static SVG end-label typography can differ slightly from live browser labels. Narrow category charts shorten or skip visible labels while retaining full labels in hover, tables and source. Locale support is a bounded convention set, not full ICU or local-time support. Numeric zoom is real but viewport transitions are less refined than mature engines. Categorical bars, pies and heatmaps do not expose continuous-axis zoom controls. ggplot2 is static. Zero diagnostic findings are not proof of equal aesthetic quality. “Escapism” and “Where to Render” remain unclarified wording.

The report/data/editor worktree and the teaser session were left untouched. This branch adds only a bounded `axes.x.locale` field, theme aliases/tokens and palette inheritance at their shared schema boundary; the active authoring PR remains a separate review branch. No reference library enters the production engine.
